# MVP Roadmap

## Phase 0 — Foundation

- Define canonical schemas and IDs
- Build company/entity resolution
- Build connector interface
- Implement raw storage and provenance
- Implement queue/workflow foundation
- Implement search index
- Create model gateway and evaluation harness

## Phase 1 — MVP intelligence

Target a small but valuable set of source classes, for example news, Reddit, YouTube, and selected public web/community sources subject to access/licensing.

Deliver:

- Company input and entity resolution
- Discovery and query expansion
- Collection and normalization
- English plus selected regional-language support
- Relevance
- Sentiment and aspect sentiment
- Topic clustering
- Basic duplicate detection
- Original source URLs
- Evidence-backed dashboard
- Historical trends
- Basic API

## Phase 2 — Advanced intelligence

- More social connectors
- Multilingual semantic clustering
- Narrative/event graph
- Impact scoring
- Source credibility
- Emotion and intent
- Geographic intelligence
- Risk engine
- Emerging-topic detection
- Alerts
- Analyst agent

## Phase 3 — Global scale

- Broad regional connector ecosystem
- Streaming collection
- Larger historical backfill
- More languages
- Advanced narrative propagation
- Enterprise governance
- Cost optimization
- Automated evaluation and drift detection
- Multi-tenant enterprise deployment

## Suggested initial milestones

### M1 — Data foundation
Schemas, source IDs, raw storage, URL provenance, company resolution.

### M2 — First intelligence pipeline
Collection, normalization, language, relevance, sentiment, topic, evidence.

### M3 — User experience
Dashboard, search, source links, trend charts, API.

### M4 — Trust layer
Deduplication, narrative clustering, source verification, credibility, confidence.

### M5 — Risk and monitoring
Emerging topics, risks, alerts, continuous monitoring.

### M6 — Scale
More sources/languages, distributed processing, historical analysis, enterprise controls.

## Success metrics

- Source coverage by region/platform
- Relevant-source precision
- Entity-resolution accuracy
- Sentiment F1/calibration
- Topic clustering quality
- Duplicate/narrative detection precision
- Evidence-grounding accuracy
- Percentage of material insights with valid source URLs
- Processing latency
- Cost per analyzed discussion
- Connector reliability
- Alert precision
